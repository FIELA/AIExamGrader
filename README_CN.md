用 OpenAI（含兼容接口）或 Google Gemini 的视觉模型批改手写答题卡：识别考生信息，按评分标准打分，为每张答题卡生成报告并汇总成绩；人工复核完成后，答题卡自动按学生重命名。

## ✨ 功能

- **自动批改**：客观题对照标准答案判分；主观题按评分细则逐小题给分，并写明得分点和失分原因。多张答题卡并行批改，中断后可以接着批。
- **评分标准**：支持 TXT、Markdown、PDF。PDF 会逐页转写成 Markdown。标准答案和答题卡布局由模型提取，你确认后才开始批改。
- **对照名单认人**：依次按文件名“考场-座号”、填涂或手写考号、手写考场座号、手写“班级+姓名”匹配学生名单，没有考号的考试也能用。
  - 班级写法会统一，701、7(1)班、七年级一班、初一1班 都算同一个班。
  - 姓名差一个字时，按相近姓名匹配并标“请核对”。
  - 拿不准的卷不自动选人，而是列出候选学生。
- **人工复核**：逐张核对考生信息、客观题、主观题；可以对照原图看，也可以只看文字；能按姓名、考号或考场-座号搜索；每次修改都有记录。
- **按学生命名答题卡**：复核完成后，每张已批改的答题卡自动重命名为“班级-姓名.jpg”（如 `701-张三.jpg`），重名自动加后缀；学生还没确认或标为“未署名”的卷保留原名。原图备份保留在“原始文件”中。
- **答题卡回写分值**：阅卷和复审后，`成功归档` 中的答题卡用红字写上分数：每个非选择题小问左侧写得分，选择题区左侧写选择题合计，标题区写总分。位置每场考试设置一次，复审改分后自动重画；红字总是从 `原始文件` 中的原图重画，原图不会被改动。
- **数据安全**：批改前先备份原图。每张答题卡对应自己的报告，重扫的卷、同名的卷都不会互相覆盖。支持中英文界面。

> [!NOTE]
> 效果取决于模型的图像识别和推理能力，建议使用较强的视觉模型。

## 🚀 安装与运行

需要 Python 3.10 及以上，macOS、Windows、Linux 均可。

```bash
pip install -r requirements.txt
```

```bash
python AutoGrader.py
```

在界面左侧填写 API Key、服务商（OpenAI / Gemini）、模型名称，以及可选的 Base URL。也可以把 `config_example.json` 复制为 `config.json` 后在其中填写，详见 [README_CONFIG_CN.md](README_CONFIG_CN.md)。

如需打包成应用：macOS 运行 `python build.py`，Windows 运行 `python build_windows.py`，生成的文件在 `dist/` 中。

## 🛠️ 使用流程

1. **准备材料**
   - 评分标准：`.txt`、`.md` 或 `.pdf`。
   - 答题卡：扫描成 `.jpg` 或 `.png`，放进同一个文件夹，沿用扫描时的文件名即可。
   - 学生名单：可选，但建议提供。Excel 或 CSV，第一行是表头，可以包含姓名、班级、考号（或学号、准考证号）、考场、座号。
2. **选择文件**：在“资源文件”区依次选择评分标准、答题卡文件夹和学生名单。
3. **开始阅卷**：点“开始阅卷”。
   - 第一次运行会先提取标准答案、识别答题卡布局，分别请你确认，再请你摆好分值位置（见第 6 步，可以“本次跳过”或“本场不启用”），然后开始批改。
   - 中途停止后再点开始，只批还没完成的卷；批改失败的卷会自动重试。
   - 批改结束时，日志会汇总认人结果：多少张已对应名单、多少张需要核对、名单中有多少人没有答题卡。同一学生对应多张卷（如重复扫描）、报告找不到对应答题卡或数量对不上时，会逐项列出，结尾提示“有 N 处需要处理”，而不是“全部完成”。
4. **复核**：点“复审”，每张卷依次核对信息、客观题、主观题，然后点“确认并继续”。没有选定学生就点确认时会弹出提示：默认点“关闭”，关闭后选定学生再确认，才进入下一份；答题卡上没有写姓名时点“未署名”，这份卷直接确认并进入下一份，成绩汇总表的“匹配方式”记为“未署名”。
   - 答题卡按扫描顺序排列，与纸质卷顺序一致；按考号或姓名改过名的卷仍在原来的位置。
   - 需要核对的卷会显示自动识别的结果，候选学生排在下拉框最前面。你改选的学生会记为“复核时选定”。
   - 同一学生还有其他答题卡时，信息栏会提示那几份卷的分数和复审状态，可能是重复扫描。核对后在多余的那份上点“移除此份”：它的图片和阅卷报告移到 `已移除` 文件夹，不再计入成绩汇总表，原图仍在 `原始文件`。请不要在访达里直接删除答题卡，否则报告会留下、数量对不上。
   - 单张卷可以点“重阅”重新批改。修改标准答案后，可以在主界面用“重评客观题”批量重算。
5. **自动重命名**：每张卷都复审过后（翻过最后一张时，如还有跳过或未复审的卷，会提示剩余份数并打开其中第一份），`成功归档` 中的答题卡就地重命名为“班级-姓名”，报告和成绩汇总表同步记录新文件名；`原始文件` 中缺少原图的卷会先补备份再改名。如果阅卷还在进行，会等阅卷结束后再次复审完成时重命名。
6. **回写分值**：在“分值位置”窗口里摆一次位置，全场答题卡都按这些位置写分（入口：第一次阅卷前自动打开，或主界面的“分值位置”按钮）。
   - 在右侧选中一项（总分、选择题合计、各小问），在样张上点击放置；拖动红字可以调整。“自动定位”会请模型在当前样张上找一次位置，只填还没放置的项，结果需要你逐项核对。
   - **一定要用“上一张/下一张”多看几张样张**：同一场考试的扫描件常有几十像素的偏移，两页拼接的卷两页偏移还可能不同。把红字放在题号左侧留些空白的位置（如框线外的页边），各张卷上就都不会压到题号和答案。红字盖住深色笔迹、互相重叠或超出图片时，窗口会提示。
   - 题目清单在没有阅卷报告时由标准答案推断，首份报告出来后自动核对：一致才开始写分，不一致会提示你在清单里增删题号。之后每张卷都按这份清单核对，报告缺小问、多出小问或总分与各题之和不一致的卷不写分，并在日志中列出原因。
   - 阅卷完成、复审确认、重阅、重评客观题之后都会自动重画；复审窗口中的图片随之更新。
   - “暂停回写”只停止之后的写分，已写上的保留；“从原图恢复（去掉分数）”用原图换回本功能写过分数的卷，文件名、成绩和复审记录不变。被你在别的软件里改过的图片不会被覆盖或恢复。
   - 重阅和重新批改只用 `原始文件` 中的原图，不会把带分数的图片送给模型；也不会把带分数的图片补备份成原图。

**文件命名小技巧**

- 已经按座位整理好的卷，可以命名为“考场-座号”（如 `01-05.jpg`），会优先用它对应名单。
- 缺考的卷在文件名里加“缺”（如 `01-05缺.jpg`、`IMG_0003缺.jpg`），汇总表会标为缺考；得 0 分的卷也会标为缺考。

## 📂 输出文件

所有结果都放在答题卡文件夹里（英文界面使用英文目录名）：

```
答题卡文件夹/
├─ 阅卷数据/      标准答案、答题卡布局、分值位置（score_marks.json）、PDF 转写结果，以及 成绩汇总表.csv
├─ 阅卷报告/      每张答题卡一份 .md 报告和 .json 数据
├─ 原始文件/      批改前的原图备份（保留扫描时的文件名，不会写上分数）
├─ 成功归档/      已批改的答题卡，启用分值位置后写有红字分数；复核完成后改名为“班级-姓名”（在此之前，文件名不是考场-座号、且识别出考号的卷，会改名为考号）
├─ 失败归档/      批改失败的答题卡，下次运行时重试
└─ 已移除/        复审中移出成绩的答题卡（如重复扫描），每次一个时间命名的文件夹，按原位置存放图片和报告，移回即可恢复
```

成绩汇总表包含：考生信息、总分、客观题和主观题各题得分、识别出的考生信息、信息校验结果、匹配方式、复审状态和缺考标记。
